# 2_QA — 품질 확인

모든 명령은 **프로젝트 폴더**에서 실행합니다. 필요한 것: Node.js 22.5 이상 · Google Chrome (다른 위치면 `CHROME=크롬경로`)

| 테스트 | 무엇을 확인하나 | 실행 | 시간 |
|---|---|---|---|
| `서버_테스트/server.test.js` | 계정 · 아이디/비밀번호 · 복구 코드 · 클라우드 저장 · 순위전 매칭/결과 합의 · 재접속 · 요청 제한 · 공개 파일 차단 (10항목) | `npm test` | 약 5초 |
| `브라우저_테스트/회원가입_로그인_e2e.mjs` | 임시 DB로 실제 서버를 띄워 회원가입 2단계 · 로그인 · 로그아웃 · 다른 기기 · 게스트 → 회원 전환 · 메뉴 · 세계 지도 · 폰 화면 (36항목) | `npm run test:auth` | 약 1분 |
| `브라우저_테스트/게임_회귀.mjs` | 오프너 · 잔해 회수 · 역전 충전 · 타격감 · 전투 요약 + 전투 흐름 그래프 · 포격 예고 조준원 · **전장 93개 AI 대전** · 폰 화면 (36항목) | `npm run test:game` | 약 3~5분 |
| `브라우저_테스트/_도구.mjs` | 게임 회귀 테스트용 공용 도구 (헤드리스 크롬 실행 · 페이지 안 코드 실행 · 스크린샷) | — | — |
| `브라우저_테스트/스크린샷/` | 테스트가 찍은 화면 (실행할 때마다 덮어씀 · git 제외) | — | — |
| `QA_결과.md` | 날짜별 결과 · 찾은 버그와 조치 | — | — |

- 통과하면 종료 코드 0, 하나라도 실패하면 1 → 배포 전에 세 가지를 모두 돌리세요
- 새 기능을 넣으면 해당 테스트에 확인 항목을 추가합니다 (`ok('설명', 조건)`)
