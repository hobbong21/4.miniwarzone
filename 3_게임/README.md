# 3_게임 — 브라우저에서 여는 게임

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 (외부 라이브러리 없음). 파일만 열어도 **게스트**로 혼자 플레이 |
| `member/login.html` · `member/signup.html` | 예전 주소 → 게임 안 🔑 로그인 · 📝 회원가입 탭으로 넘김 |

- 회원가입 · 로그인 · 순위전 PVP는 서버로 실행해야 합니다 (프로젝트 폴더의 `start.bat` / `start.sh`, 또는 `npm start`)
- 로그인 화면: 🔑 로그인 · 📝 회원가입(① 계정 만들기 → ② 지휘관 등록) · 🎖️ 게스트(지휘관 등록만)
- 시스템 설명은 [`../1_기획서/미니워존_기획서.md`](../1_기획서/미니워존_기획서.md)
