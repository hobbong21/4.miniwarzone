# 미니워존 (Mini War Zone)

등고선 위의 작은 전쟁 — 브라우저에서 바로 하는 2.5D 실시간 전략 게임 · 개발 **휴먼에이드 (HumanAid)**

## 폴더 안내 — 하려는 일에 따라 여기로

| 하려는 일 | 폴더 | 들어 있는 것 |
|---|---|---|
| ▶ 그냥 실행해 보기 | `start.bat` (Windows) · `start.sh` (macOS · Linux) | 더블클릭 → 서버를 켜고 브라우저로 게임을 엶 |
| 📖 게임이 어떻게 돌아가는지 · 새 기능 기획 | [`1_기획서/`](1_기획서/미니워존_기획서.md) | `미니워존_기획서.md` (§ 번호로 찾기) · `회원가입_로그인_주소.md` · `이미지/` |
| ✅ 잘 돌아가는지 확인 · 테스트 | [`2_QA/`](2_QA/README.md) | 서버 테스트 · 브라우저 자동 테스트 · `QA_결과.md`(날짜별 결과 · 버그) |
| 🎮 게임 화면 · 코드 수정 | [`3_게임/`](3_게임/README.md) | `index.html`(게임 전체) · `member/`(예전 주소) |
| 🖥️ 계정 · 저장 · 순위 · PVP 서버 | [`4_서버/`](4_서버/README.md) | `server.js` · `api.js` · `db.js` · `ws.js` · `rating.js` · 환경 변수 · API 설명 |
| 📦 서버에 올리기 | [`5_배포/`](5_배포/README.md) | `Dockerfile` · 배포 방법 · GHCR 이미지 |
| 💾 서버 기록 | `data/` | DB (자동 생성 · git 제외 · **백업 대상**) |

## 바로 해 보기

- **혼자 하기 (설치 없음)**: `3_게임/index.html`을 브라우저로 열기 → 게스트로 플레이
- **회원 · 순위 · PVP**: `start.bat` / `./start.sh` 더블클릭, 또는 `npm start` → http://localhost:8080 (Node.js 22.5 이상)
- **테스트**: `npm test`(서버) · `npm run test:auth`(회원가입 · 로그인) · `npm run test:game`(게임 회귀)

## 관리 원칙

- 브랜치는 `main` 하나만 씁니다. 버전 백업 파일(`index_v*.html`)은 만들지 않고 git 기록으로 관리
- 기능을 바꾸면 ① 기획서에 § 항목 추가 → ② `2_QA` 테스트 실행 → ③ `2_QA/QA_결과.md`에 기록
